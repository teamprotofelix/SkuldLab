# 상세 장면 이미지 제작

내장 이미지 생성 도구 사용. 각 기존 구역 이미지를 스타일 참조로 사용하였으며, 결과를 WebP로 변환했다. 화면의 글자나 UI를 이미지에 합성하지 않도록 요청했다. 생성 원본은 배포하지 않는다.

- 제작실: 따뜻한 미래형 로봇 작업실, 분홍색과 아이보리색 토끼 로봇 시제품과 황동 작업대, 별과 떠 있는 섬, 캐릭터를 배치할 수 있는 앞쪽 바닥.
- 비행 도크: 흰색과 분홍색 토끼 귀를 가진 2인승 우주선과 탑승 플랫폼, 성운과 떠 있는 섬, 넓은 앞쪽 바닥.
- 리액터: 세계수 뿌리를 감싼 청록색 공명 구체와 흰색·황금색 장치, 옆쪽 조작대, 우주가 보이는 높은 창과 열린 앞쪽 바닥.
