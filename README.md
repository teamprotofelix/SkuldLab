# SKULD LAB — Astraho R&D Laboratory

스쿨드의 연구실을 탐험하고, 발명품을 열람하고, 기체를 조립하며, 세 가지 실험을 즐기는 **정적 웹사이트**입니다.

## 주요 기능

- 6개 연구 구역 인터랙티브 갤러리와 대화 가이드
- 8개 발명품 카드와 상세 정보 / 관심 등록
- 프레임×동력 코어×모듈 조합으로 로봇 설계, 시각화, 로컬 저장 / JSON 출력
- 리액터 출력·냉각·실드 안전 시험 (가상 계산)
- 회전 위상에 맞춘 게이트 동기화 게임
- 키보드·터치 대응 밤페이 비행 미니게임
- 스쿨드 16프레임 스프라이트, 밤페이 8프레임 스프라이트
- WebP 배경/도면, 오프라인 PWA 지원, 반응형 모바일 레이아웃

## 배포

`index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `assets/`를 저장소 루트에 두면 됩니다. GitHub Pages에서 `Settings → Pages → Deploy from branch → main / (root)`를 설정하면 `https://teamprotofelix.github.io/SkuldLab/`에서 열람 가능합니다. 실제 GitHub Pages 설정/배포 상태는 별도 확인이 필요합니다.

별도의 서버, Node.js 또는 API 키가 필요하지 않습니다. 로컬 미리보기는 아래 명령으로 실행합니다.

```bash
python -m http.server 8080
```

`http://localhost:8080` 접속. `file://` 직접 열람 시 서비스 워커는 동작하지 않습니다.

## 이미지 제작 / 라이선스

`assets`의 배경·발명품 일러스트·스프라이트는 이 프로젝트를 위해 Python Pillow로 **절차적 생성한 오리지널 그래픽**입니다. 모든 풍경/장비/캐릭터 이미지가 실제 우주선 사진이나 원작 애니메이션의 스크린샷은 아닙니다. 마스코트는 이 프로젝트의 캐릭터 해석으로 그린 창작 스프라이트입니다. `make_assets.py`를 실행하면 재생성할 수 있습니다.

원작 및 관련 캐릭터의 권리는 각 권리자에게 있습니다. 이 저장소는 비공식 팬 창작 프로젝트이며 상업적/공식 제휴를 뜻하지 않습니다.

## 안전성 / 개인정보

- 본 사이트는 세계관 기반 **가상 시뮬레이션**입니다. 실제 우주선, AI 모델, 외부 API와 통신하지 않습니다.
- 모든 설계도와 관심 정보는 방문자의 브라우저 localStorage에만 저장됩니다. 별도 서버 전송 기능이 없습니다.
- 사이트의 코드를 검토할 때 외부 이미지 URL이나 외부 JS 의존성이 없음을 확인할 수 있습니다.
- PWA 업데이트는 `sw.js` 캐시 버전 변경으로 진행합니다. 외부에서 사용자 계정 정보를 요구하지 않습니다.

## 정전과 새 창작의 구분

Banpei Head, Guardian 사건, 에이온 위그드라실 등 아스트라호 설정에서 영감을 얻은 내용은 세계관 기록에 기반합니다. 하트비트 감응 센서/그라비티 룸/포켓 게이트 등 일부 기기, 게임 결과와 로봇 조합은 **사이트 전용 컨셉**이며 정전 아이템으로 자동 편입되지 않습니다.

## 향후 로드맵

아스트라호 함선 맵 연동, 더 풍부한 조립 부품, 연구 커뮤니티, 방문자별 설계 동기화, 절차적 발명 도전 모드. 현재 버전은 제3자 서비스 연동 없는 정적 사이트입니다.
