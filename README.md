# SKULD LAB 2 — Dimensional Research Archipelago

아스트라호와 귀환 포털로 이어진 스쿨드의 **차원 연구소**. 우주에 떠 있는 일곱 연구 섬을 탐험하고, 구성원과 이동하고, 밤페이로 다른 하늘을 여행하는 서버 없는 정적 사이트입니다.

## 체험

- **LAB MAP:** 일곱 모듈의 생성 일러스트 위에서 13종 구성원이 네 방향 보행 프레임으로 이동합니다. 구성원 선택·말 걸기·따라보기·목적지 이동·생활 애니메이션 일시정지를 지원합니다.
- **모듈 입장:** 로봇 제작실, 공명 리액터, 세계수 공명실, 차원 포털, 밤페이 비행 도크, 울드의 연금 공방, 중앙 설계 아틀리에. 각 모듈에서 관련 실험으로 이동합니다.
- **FLIGHT VIEW:** 자동 항법과 방향키/WASD/터치 수동 조종. 연구 조각 수집, 장애물·실드·보호 복구, 속도 조절, 일시정지, 재시작. 성운·공룡 초원·공중 도시의 세 항로가 순환합니다.
- **연구 여권:** 설계도 저장·리액터 안정화·게이트 연결·세계수 회로·포션 배합·탐사 조각 수집의 여섯 임무. 저장한 설계는 지도에 시험 로봇으로 등장합니다. 지도상의 시험 로봇은 공통 밤페이 외형이며 부품별 수치는 작업대에서 표시합니다.
- **기존 기능 유지:** 8종 발명품 상세/관심 등록, 27가지 로봇 조합, 설계도 JSON 내보내기, 리액터·게이트·기존 정찰 게임.
- **PWA:** 로컬 오프라인 열람, 앱 설치, 방문자가 누르는 업데이트 적용. 설계도와 여권은 같은 도메인의 이 브라우저에 보관됩니다.

`CNAME`의 기존 `skuldlab.moip.ai.kr`을 보존합니다. GitHub Pages의 기존 main 루트 배포를 사용하며, 다른 두 저장소의 main은 수정하지 않습니다.

## 파일과 실행

빌드나 API 키, 외부 CDN이 필요 없습니다. 저장소 루트를 정적 호스팅하세요. `file://`로 열면 ES 모듈과 PWA 제약 때문에 전체 기능을 사용할 수 없습니다.

```sh
npm test
npm run check
python tests/verify.py
```

DOM 통합 검사는 설치된 jsdom의 진입점 경로를 인수로 받습니다.

```sh
node --experimental-vm-modules tests/dom-check.mjs /absolute/path/to/jsdom/lib/api.js
```

이 검사는 HTML과 실제 두 스크립트를 함께 실행하지만 **브라우저의 화면 렌더링이나 실제 터치를 검증하지 않습니다**. Node 외에 런타임 의존성은 없으며 `verify.py`는 Pillow를 사용합니다.

## 이미지와 스프라이트

새 연구소 전경·모듈·항로·발명품과 스프라이트 등 총 32개 이미지를 이미지 생성 모델로 제작했습니다. 원본 PNG 약 75.2MB를 WebP 약 4.44MB로 줄였으며, 유지한 기존 파일까지 포함한 전체 WebP는 약 4.64MB입니다. 원본 PNG는 배포에 포함하지 않습니다. 인물 시트는 **스쿨드·밤페이·E·미스티아 서아·미르·울드·2B·마리·요르·아멜리아·세레나·자비스** 12종을 새로 생성했습니다. 완다는 생성 도구 오류로 같은 사용자의 `teamprotofelix/Jarvis_Astraho` 시트를 재사용하고 크기를 맞췄습니다.

구성원 시트는 384×640px, 3열×4행, 셀 128×160px입니다. 행은 남·서·동·북, 열은 세 보행 프레임입니다. 밤페이 2인승 전용기의 비행 시트는 별도 900×240px, 3프레임입니다. 투명 알파를 보존하며 CSS 배경 위치와 캔버스 원본 사각형으로 프레임을 선택합니다. 이동 경로는 중앙 아틀리에를 연결점으로 사용하는 가상 생활 경로입니다.

`docs/asset-manifest.json`에 출처 구분·PNG 대비 크기·최종 해시를 기록했습니다. `tools-optimize-assets.py`는 원본 이미지 경로 매핑을 받아 포맷과 프레임 규격을 정리하는 개발 도구입니다. 기존 `make_assets.py`는 v1 절차적 그래픽 생성기이므로 현행 일러스트를 교체할 의도가 없으면 실행하지 마세요.

## 세계관

아스트라호는 살아 있는 신의 방주이며 연구소는 그 R&D 모듈에서 차원 포털로 연결됩니다. 차원 군도 배치, 자비스의 구체형 연구 드론, 실험 임무와 게임은 **이번 사이트를 위해 확장한 창작**입니다. 대사는 공개 전시용으로 새로 작성했으며 개인 대화 원문을 게시하지 않습니다. 실제 AI 호출이나 기계 제어는 없습니다.

Banpei Head Skuld Exclusive Mk.1과 공룡 소풍, Guardian의 안전 중심 기술, 에이온 위그드라실은 제공된 아스트라호 기록에서 가져왔습니다. 자비스는 시스템 진단을, 서아는 인적 지휘를, 스쿨드는 수리·발명을 맡는 차이를 유지합니다.

비공식 팬 창작 프로젝트입니다. 관련 캐릭터의 권리는 각 권리자에게 있습니다.
