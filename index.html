WELCOME TO SKULD LAB

연구소 이용 안내

모듈 이름을 눌러 전경과 실험을 열어 봐. 오른쪽 구성원을 선택하면 그 친구의 위치와 이야기를 볼 수 있어.

‘함께 이동’은 연결 다리를 따라 이동을 예약해. ‘따라보기’는 선택한 친구가 보이도록 지도를 움직여 줘.

FLIGHT VIEW에서 출격 후 자동 조종으로 풍경을 감상하거나 수동 조종으로 직접 탐사할 수 있어. 방향키·WASD는 비행 화면에 포커스가 있을 때 동작해.

여섯 가지 임무와 설계도는 이 브라우저에 저장돼. 모션 감소 설정에서는 생활 애니메이션이 멈추며, 출격은 직접 눌러 시작할 수 있어.

자비스의 구체형 드론과 차원 군도 배치는 이번 사이트를 위한 창작이야. 공개 대사는 세계관을 바탕으로 새로 작성했어.

  1. Android · Chrome / Edge
    브라우저 메뉴 ⋮ → ‘앱 설치’ 또는 ‘홈 화면에 추가’를 선택해 줘.
  2. iPhone · iPad / Safari
    공유 버튼 → ‘홈 화면에 추가’ → ‘추가’를 눌러 줘. ‘웹 앱으로 열기’가 보이면 켜 두면 돼.
  3. PC · Chrome / Edge
    주소창의 설치 아이콘 또는 브라우저 메뉴의 앱 설치를 선택해 줘.

앱 이름은 ‘스쿨드 연구소’야. 설치 후 홈 화면이나 앱 목록의 밤페이로 바로 들어와! 한 번 방문해 저장이 끝난 뒤에는 오프라인에서도 연구소를 열 수 있어.

이미 설치한 앱에 이전 아이콘이 남으면 브라우저가 갱신할 때까지 기다리거나, 같은 주소에서 앱을 다시 설치해 줘. 연구 기록을 유지하려면 사이트 데이터는 지우지 마.
